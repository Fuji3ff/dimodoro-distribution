Dimodoro 内部テスト

テスト版はGoogle Playから配布します。APKの直接配布は終了しました。

Google Playの内部テストに参加

招待されたGoogleアカウントで開いてください

かんたん手順

  1. 「Google Playの内部テストに参加」を押す
  2. 招待されたGoogleアカウントでテスターになる
  3. Google PlayからDimodoroをインストールする

参加できない場合

Playストアで使っているGoogleアカウントが、内部テスターとして招待済みか確認してください。
